System guide

From a sign to a reviewed message.

HandSpeak is an experimental ASL learning and recognition application. Use this walkthrough to present its working features and explain its limits.

1. Learn and recognize

Open the translator and allow camera access. Choose Static letters for A, B, I, L, V, W, and Y. Hold a letter steady, then lower your hand before repeating it. The digit 5 requires personal training.

For isolated words, watch a gesture video and select Words in motion. Sign once, then pause. Review suggestions before selecting Add matched word. Use Record a word when automatic capture misses the movement.

The default words are HELLO, THANK YOU, PLEASE, YES, NO, and FINISH. DRINK, WATER, BOOK, FOOD, HUNGRY, LIKE, and GO are an optional preview with weaker accuracy. Normal, half-speed, quarter-speed, replay, and repeat video controls are available.

The searchable library contains 200 requested entries in 15 categories. Each card distinguishes a video, external lesson, and experimental recognition preview. New category models failed evaluation and are not enabled. Entries marked No enabled model require personal examples; adding typed text is not camera recognition. The site includes 59 practice clips.

2. Review and communicate

Try Interpret draft with “I WANT WATER PLEASE.” The local LLM suggests English wording. Compare the original with the suggestion, choose Use suggestion, and demonstrate Restore original words. It cannot verify a sign or infer ASL grammar; suggestions may be wrong and never speak automatically.

Build a draft from separate words. Automatic draft adding is optional and never speaks by itself. Add typed words such as I and AM, remove the last word, add punctuation, then edit the sentence. Typed words are not camera recognition.

Edit the message to correct or type text. Demonstrate Copy text and Speak message. A message is never automatically spoken just because the word recognizer suggests a match.

If camera access is unavailable, Try demo simulates three letters. This is clearly labeled as a presentation example and is not evidence of AI recognition.

3. Save your work

Use the website as a guest. Save a reviewed message, refresh history, reuse it, export CSV, and delete the test message. A different browser cookie must not see your history. Clearing cookies removes access to guest history.

Submit the feedback questionnaire once. Its ratings describe user experience; they are not a measured recognition accuracy score.

4. Show administration and database storage

Sign in as the administrator and open the Admin dashboard. Show account totals, feedback, activation/deactivation, and password-reset links using a test account. Do not deactivate the presenter’s account.

Open phpMyAdmin from the dashboard. Use the separate database login. The live MariaDB database contains users, sign-in sessions, password-reset tokens, gestures, saved messages, detection statistics, and feedback. Passwords and account session tokens are hashed. Never project credentials or password-reset links during the defense.

Architecture and privacy

Browser: camera capture, MediaPipe landmarks, static-letter and motion-template classification, face landmarks, gesture videos, and message editing. Personal gesture samples remain in browser storage.

Application server: account authorization, message ownership, validation, feedback, and export. MariaDB: persistent application records. phpMyAdmin: administrator-only database management. nginx: HTTPS and routing.

No camera frames are uploaded. Saving sends reviewed text and letter-detection statistics to the server. Clicking Interpret draft sends only the draft text to a local Qwen model on this server. Interpretation does not automatically save it or send it to a cloud LLM. Feedback is not linked to an account, but administrators can read its comments. Database backups remain private on the server.

Explain the measured limits

This system recognizes selected isolated signs. It does not translate continuous ASL, interpret ASL grammar, identify a person, or determine emotions. The face display describes visible facial movements.

In the recorded small six-word test, 38 of 72 selected clips were correctly recognized, including tracking failures in the denominator. The latest four-word addition recognized 5 of 24 reserved new-word clips and increased unsupported false suggestions from 24 to 26 out of 40 regression examples. GO had no correct matches in its six test clips. These results are not a live-camera accuracy guarantee. The alternative temporal-model experiment was not promoted because it failed the automatic unknown-rejection gate.

The first expanded category experiment matched 46 of 190 clips for its 48 trained labels. It is not high accuracy. Category results and later experiment limits are available in the evaluation file. Later recovery and broader-negative training experiments did not pass the replacement gate. High accuracy remains unproven. The original default vocabulary is preserved.

Email verification, email delivery, and MFA are not configured. Password recovery uses administrator-issued, single-use reset links. Backups are scheduled daily on this server; separate off-site disaster recovery is not configured.

Before the presentation

Check HTTPS, browser camera permission, lighting, internet access for the vision runtime, audio output, and your administrator sign-in. Rehearse the chosen signs with the actual presentation device. Use a separate guest browser profile for demonstrations, clean up test messages afterward, and keep a private database backup.
